Markup Bridge

Visual UI feedback bridge for Antigravity

v2.0.3
Checking daemon status...

Workflow

Submit visual feedback in the browser and apply it in Antigravity.

1
Start the bridge server
Run this command in your project terminal:
npx markup-bridge@latest
2
Select element and submit
Open your webpage, press Alt + Shift + X, click any element, enter your notes, and click Send to Antigravity.
3
Execute in Antigravity chat
In your Antigravity chat prompt, type /markup to review and execute pending changes:
/markup

Commands

Manage the local bridge process.

Restart Server (macOS / Linux)
lsof -ti:3005 | xargs kill -9 && npx markup-bridge@latest
Restart Server (Windows)
npx kill-port 3005 && npx markup-bridge@latest
Uninstall Project Configuration
npx markup-bridge uninstall
