🚀 How It Works (3 Simple Steps)

Collect visual feedback in your browser, then let Antigravity implement the changes with a single command.

1
Start the Bridge Daemon
Run this once in your project root terminal. It starts the local bridge server (port 3005) and configures Antigravity MCP tools automatically:
npx markup-bridge@latest
2
Inspect & Submit in Browser
Press Alt+Shift+X or click the floating pill. Click any element or draw an area box, type your requested UI changes, and click Send to Antigravity (or 📋 Copy Prompt).
3
Execute in Antigravity Chat
Open Antigravity IDE and in your chat prompt, simply type:
/markup
✨ Antigravity will instantly read all pending UI changes, edit the files in your project, mark them resolved, and turn the browser pins green in real time!

🛠️ Useful Commands

Helpful commands for troubleshooting and managing your bridge server.

Restart Daemon (Clean Port 3005)
lsof -ti:3005 | xargs kill -9 && npx markup-bridge@latest
Remove Project Integration
npx markup-bridge uninstall
