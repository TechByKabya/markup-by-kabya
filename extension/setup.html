Zero Project Modification Required
This Chrome extension injects the floating widget and inspector across all browser tabs and windows at runtime. You do not need to install npm packages, add script tags, or modify your React, Next.js, Vue, Svelte, or HTML codebase.

1 Load Extension into Chrome

Anyone can install this extension into Google Chrome in seconds using Developer Mode:

  1. Open Chrome and navigate to chrome://extensions
  2. Enable the Developer mode toggle in the upper-right corner.
  3. Click Load unpacked and select the extension folder in this project (or extract markup-bridge-extension.zip).
  4. The Markup Bridge icon will appear in your toolbar, and the floating shortcut pill will show on all pages.

2 Configure Antigravity IDE

Connect Antigravity to the Markup Bridge MCP server by adding this configuration to your project's .agents/mcp_config.json:

.agents/mcp_config.json 
{
  "mcpServers": {
    "markup-bridge": {
      "command": "node",
      "args": ["/absolute/path/to/markup-by-kabya/bin/markup-bridge.js", "mcp"],
      "env": {
        "BRIDGE_API_BASE": "http://127.0.0.1:3005"
      }
    }
  }
}

Alternatively, execute node bin/markup-bridge.js init in this project directory to generate this file automatically with the correct absolute path.

3 Start Bridge Daemon

Run the local bridge daemon in any terminal window. This manages the feedback queue and provides real-time Server-Sent Events (SSE):

Terminal 
npm run server

When active, the server runs at http://127.0.0.1:3005 and saves feedback to .antigravity/ui_feedback_queue.json.

4 Universal Controls & Inspection Modes

Click the bottom-right floating pill on any web page or press Alt + Shift + X to activate the inspector.

Mode / Action Shortcut / Icon Description
Toggle Inspector Alt + Shift + X Opens or closes the overlay and mode toolbar on the active tab
Element Inspector Element Hover and click any DOM element to capture selector, React Fiber hierarchy, and computed styles
Rectangle Marking Box Click and drag across empty whitespace, margins, or components to define exact pixel regions
Circle Marking Circle Click and drag to circle specific focal points or components
Point Pin Pin Single-click anywhere to place a point coordinate marker
Submit Feedback Cmd / Ctrl + Enter Sends note and snapshot to queue; Antigravity wakes up automatically
